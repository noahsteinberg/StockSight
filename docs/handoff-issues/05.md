# Model integration later: trusted artifact parity, offline inference and outcome resolution

Priority: deferred until a candidate passes the recorded evaluation/promotion process. Depends on prediction persistence, hosted data readiness and the paused ML decision.

Scope:
- Export only a reviewed artifact bundle with model/code/data versions, feature order, package pins, input/target/price-basis semantics and file hashes.
- Point-in-time feature and golden prediction parity between research and inference.
- Offline settled-daily-bar job loads approved artifact and writes immutable prediction batches; no training or full-universe feature building in a Vercel request.
- Separate outcome resolver/evaluation job; unavailable reasons for missing/stale/bad/unsettled input or artifact mismatch.
- Existing FastAPI bounded GET reads feed existing React pages. Recommendations use relative-target language when that is the supported evidence.

Acceptance: parity/hash/idempotency/calendar tests, shadow batch and rollback-to-unavailable path before public activation. Never deserialize user-uploaded pickle/joblib. Do not auto-retrain or publish raw probabilities as confidence.
